Automotive systems engineer with experience in OBD and UDS diagnostics, fault-monitoring strategies, electrified powertrain systems, DFMEA / DFMEA-MSR, requirements development, software test automation, SIL / virtual ECU testing, and vehicle-level verification and validation.

My work connects system functions and failure modes to diagnostic requirements, monitor logic, fault responses, communication requirements, and verification criteria across regulatory, powertrain, charging, battery, and control-system applications.

Selected Engineering Work

  • GPF diagnostic requirements: Developed requirements from regulatory needs and failure modes, allocated functions to software, controls, and calibration teams, and defined verification and vehicle-validation criteria.
  • xEV ECU fault monitoring: Developed ECU diagnostic requirements using UDS / OBD concepts including DTC definitions, DIDs, diagnostic sessions, fault detection, recovery criteria, and service-level communication.
  • BMS and onboard-charger diagnostics: Developed fault-detection routines including over-voltage, over-temperature, and cell-balancing strategies.
  • DFMEA / DFMEA-MSR: Performed diagnostic-coverage analysis for engine, hybrid-control, ESS, and powertrain systems and supported mitigation strategies.
  • UDS / DoCAN testing: Created diagnostic test cases for controller commands and measurements and developed Python / CAN-tool automation for software testing and defect identification.
  • Charging interoperability: Validated AC / DC charging communication, handshakes, current ramp-up, vehicle-grid interoperability, and fail-safe behavior.
  • SOC estimation: Developed a Kalman-filter and open-circuit-voltage based battery State-of-Charge estimation algorithm.
