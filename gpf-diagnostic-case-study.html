Overview

GPF Diagnostic Development

A diagnostic analysis for a Gasoline Particulate Filter (GPF), linking soot capture, storage, and regeneration to failure modes, monitor concepts, and implementation responsibilities.

01

Objective / Problem

Identify how the GPF can lose or degrade its intended function, which effects could be observed, and which diagnostic concepts could detect those conditions.

FiltrationCapture soot
Loading capacityStore soot
RegenerationBurn soot

The analysis covers reduced filtration, excessive loading, reduced storage capacity, restriction, and regeneration faults. The intended output is a traceable diagnostic concept that can be developed into measurable requirements.

02

Requirements / Standards

The working requirements below describe the diagnostic intent. Numerical limits, enabling conditions, and regulatory references remain to be defined for the target vehicle program.

R1Filtration performance

Identify degraded soot capture or a bypass path. Define the measurable signal or model response used to distinguish a healthy filter from a failed one.

R2Loading and restriction

Assess soot loading and restriction using pressure information and a soot-load model. Define operating conditions and diagnostic thresholds.

R3Regeneration behavior

Evaluate regeneration initiation, completion, and thermal behavior. Define valid temperature ranges and expected changes in soot loading.

R4Diagnostic decisions

Specify sensor plausibility checks, detection timing, diagnostic status, and the required system response for each confirmed fault.

Standards baseline

The current draft does not cite a specific emissions or OBD regulation, clause, or model year. Establish that baseline and link each applicable clause to a requirement before setting final acceptance criteria.

Sensing

Pre- and post-GPF pressure taps feed the differential-pressure sensing path. Upstream and downstream temperature sensors provide thermal inputs.

ECU / OBD logic

Sensor inputs and model estimates support plausibility checks, fault detection, and diagnostic status decisions.

Regeneration controls

The ECU interfaces with engine and regeneration controls to coordinate the response to monitored conditions.

Signal path: pressure and temperature sensing → ECU diagnostic logic → engine / regeneration controls. The allocation is a concept-level view; sensor specifications and interface timing are not defined in the source.

04

Verification / Results

The current deliverable is a draft analysis and allocation model. The published source contains no executed test cases, measured results, detection thresholds, or pass/fail evidence.
