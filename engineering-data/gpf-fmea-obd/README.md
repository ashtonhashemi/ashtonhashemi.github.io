# GPF FMEA / OBD Working Draft

Editable source data for the GPF FMEA / OBD portfolio case study.

## Files

- `gpf-fmea-obd.json` — structured source of functions, failure modes, effects, monitor concepts, physical components, and interfaces.
- `gpf-functional.mmd` — Mermaid source for the functional/FMEA view.
- `gpf-physical.mmd` — Mermaid source for the physical decomposition/allocation view.

## Current functional decomposition

1. Capture soot
2. Store soot
3. Burn soot

The files intentionally contain no Mermaid styling, colors, severity ratings, occurrence ratings, detection ratings, or RPN values. They are meant to be edited as the analysis is refined.
